**Результат:**
static logic
logic (1) id=0
logic (2) id=1
ctor id=100

**Объяснение:**
- **static logic** — статический блок выполняется первым при загрузке класса, до создания любого объекта
- **logic (1) id=0** — нестатический блок выполняется до конструктора, поле `id` ещё не инициализировано, поэтому выводится значение по умолчанию для `int` — `0`
- **logic (2) id=1** — следующий нестатический блок, выполняется после инициализации поля `private int id = 1`, поэтому выводится `1`
- **ctor id=100** — конструктор выполняется последним, присваивает полю `id` переданное значение `100`
