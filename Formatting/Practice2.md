Метод flush() принудительно выталкивает (записывает) данные из буфера в конечное устройство вывода (файл, консоль, сеть). Буферизованные потоки накапливают данные в памяти для оптимизации, и без flush() часть данных может остаться в буфере. При ошибке программа завершится, и данные потеряются. Метод close() автоматически вызывает flush().
