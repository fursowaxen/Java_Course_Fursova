Каким соглашениям должна следовать реализация equals():

Метод equals() должен удовлетворять пяти требованиям: рефлексивность (x.equals(x) == true), симметричность (x.equals(y) == y.equals(x)), транзитивность (если x.equals(y) и y.equals(z), то x.equals(z)), постоянство (при неизменных данных результат не меняется) и не-null (x.equals(null) == false). Также при переопределении equals нужно всегда переопределять hashCode.
