IntegerCache кэширует целые числа в диапазоне от -128 до 127.
- Для числа 127 (в диапазоне кэша): при автоупаковке оба объекта a2 и b2 ссылаются на один и тот же объект из кэша. Поэтому a2 == b2 возвращает true.
- Для числа 128 (вне диапазона кэша): при автоупаковке создаются два разных объекта. Поэтому a1 == b1 возвращает false.
- Оператор == сравнивает ссылки у объектов и значения у примитивов.

- Метод equals() всегда сравнивает значения, поэтому во всех случаях возвращает true.
