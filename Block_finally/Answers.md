- Практика 1: Нет, нельзя. Конструкция try { ... } без catch или finally вызовет ошибку компиляции. Блок try должен сопровождаться хотя бы одним catch или finally.

- Практика 2: Да, можно. Конструкция try { ... } finally { ... } допустима. Используется, когда нужно гарантированно выполнить код (например, закрыть ресурсы), но исключение не обрабатывается, а пробрасывается выше.

- Практика 3: Нет, нельзя. Блок finally может быть только один. Наличие двух блоков finally вызовет ошибку компиляции.
